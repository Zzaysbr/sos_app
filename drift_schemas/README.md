# Versioned Drift schemas

These snapshots are migration-test inputs, not runtime configuration.

- `drift_schema_v5.json` was generated by Drift 2.35.1 from the committed
  `AppDatabase` source at
  `c6e0b5335b7d77eda9fe4a3fa769bddf629fe4e3` in an isolated source archive.
  That commit declares schema version 5 and the five pre-relay tables.
- `drift_schema_v6.json` was generated by Drift 2.35.1 from the current
  additive Relay Stage 1 schema.
- `test/generated_schema.dart/` and `test/generated_migrations.dart` are
  generated from these snapshots by `drift_dev schema generate` and
  `drift_dev schema steps` respectively.

Regenerate a snapshot only from the source revision that originally owned
that schema version. Never recreate an old version by manually transcribing
DDL from the current schema.
